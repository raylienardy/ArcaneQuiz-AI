## Tentang Proyek OpenQuiz AI

Ini adalah aplikasi web yang bisa membuat soal ujian (pilihan ganda, esai, benar/salah) secara otomatis dari file PDF, Word (.docx), atau teks biasa (.txt). Aplikasi ini menggunakan AI (kecerdasan buatan) untuk menghasilkan soalnya.

**Teknologi yang digunakan (tidak perlu dijelaskan ke teman saya):**
- **Backend (server):** Python dengan FastAPI
- **Frontend (tampilan):** React + Vite

**Struktur folder proyek:**
```
openquiz-ai/
  ├── backend/     ← Kode server (Python)
  └── frontend/    ← Kode tampilan website (React)
```

**Semua file dokumentasi sudah dihapus agar rapi.** Teman saya hanya memiliki folder `backend` dan `frontend` beserta isinya.

## Konfigurasi AI Provider (PENTING)

Di dalam folder `backend`, ada file bernama `.env.example`. Teman saya harus **menyalin file itu menjadi `.env`**, lalu mengisinya dengan **salah satu** dari tiga pilihan AI berikut. **Kamu harus menjelaskan cara memilih dan mengisi file `.env` ini dengan sabar.**

### Pilihan 1: Mock AI (GRATIS, tanpa internet, hasil soal statis)
```
AI_PROVIDER=mock
```
*Cocok untuk uji coba cepat, tidak butuh API key.*

### Pilihan 2: Groq AI (GRATIS, butuh internet, hasil soal lebih pintar)
```
AI_PROVIDER=groq
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxx
GROQ_MODEL=llama-3.1-8b-instant
```
*API key gratis bisa didapat dari https://console.groq.com (daftar pakai Google).*

### Pilihan 3: Gemini AI (Google, gratis terbatas)
```
AI_PROVIDER=gemini
GEMINI_API_KEY=xxxxxxxxxxxxxxxxxxxx
GEMINI_MODEL=models/gemini-2.0-flash
```
*API key gratis dari https://aistudio.google.com/apikey.*

**Kamu harus menjelaskan bahwa jika dia bingung, gunakan Mock AI dulu saja (Pilihan 1) karena paling mudah.**

## Cara Menjalankan Aplikasi (Ringkasan untuk ChatGPT)

Berikut ringkasan teknis yang bisa kamu terjemahkan ke bahasa awam:

### Backend (Python)
1. Buka terminal di folder `backend`.
2. Buat virtual environment: `python -m venv .venv`
3. Aktifkan: `.venv\Scripts\activate` (Windows)
4. Install dependensi: `pip install -r requirements.txt`
5. Buat file `.env` dari `.env.example` dan isi sesuai pilihan AI.
6. Jalankan server: `python -m uvicorn app.main:app --reload`
7. Server berjalan di `http://localhost:8000`.

### Frontend (React)
1. Buka terminal baru di folder `frontend`.
2. Install dependensi: `npm install`
3. Jalankan server: `npm run dev`
4. Buka `http://localhost:5173` di browser.

### Penggunaan Aplikasi
- Upload file (.pdf/.docx/.txt) maks 20MB.
- Klik "Generate Questions" untuk membuat soal.
- Review soal, lihat detail, statistik.
- Klik "Export PDF" untuk mengunduh soal dalam PDF.

### Troubleshooting
- "python: command not found" → Python belum terinstal atau tidak di PATH.
- "npm: command not found" → Node.js belum terinstal.
- Error 429 → Kuota AI habis, ganti ke Mock.
- Halaman putih → Buka F12, lihat Console, catat errornya.
